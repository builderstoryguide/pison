# PDF Export Feature for Financial Records

## Overview

The PDF Export feature allows administrators to download financial records in PDF format for reporting, record-keeping, and sharing purposes. This feature provides professional, well-formatted PDF reports with comprehensive financial data.

## Features

### 1. Multiple Report Types

- **Payment Report**: All payment records with detailed information
- **Fee Structure Report**: All fee structures and their amounts
- **Outstanding Fees Report**: Students with outstanding balances
- **Comprehensive Report**: Complete financial overview with all data

### 2. Professional PDF Formatting

- Clean, professional layout with proper styling
- School branding and header information
- Financial summaries with key metrics
- Detailed tables with all relevant data
- Status badges and color coding
- Page numbering and proper pagination

### 3. Export Options

- Individual tab exports (Payments, Fee Structures, Student Fees)
- Comprehensive export with all financial data
- Automatic file naming with timestamps
- Direct download to user's device

### 4. Fallback System

- **Primary**: Puppeteer-based PDF generation for high-quality output
- **Fallback**: Simple HTML generator for environments where Puppeteer fails
- Automatic fallback when primary generator encounters errors

## Technical Implementation

### 1. PDF Generation Engine

**Primary Technology**: Puppeteer (Headless Chrome)
- Generates high-quality PDFs from HTML templates
- Supports complex layouts and styling
- Handles large datasets efficiently
- Cross-platform compatibility

**Fallback Technology**: Simple HTML Generator
- Generates HTML files that can be opened in browsers
- No external dependencies
- Works in all environments
- Automatic fallback when Puppeteer fails

### 2. File Structure

```
lib/
├── pdf-generator.ts          # Primary PDF generation utility (Puppeteer)
├── simple-pdf-generator.ts   # Fallback PDF generation utility (HTML)
├── financial-context.tsx     # Financial data management

hooks/
└── use-pdf-export.ts         # PDF export hook

app/
├── api/financial-reports/
│   └── route.ts              # API endpoint for PDF generation
├── test-pdf-export/
│   └── page.tsx              # Test page for PDF export
└── test-pdf-debug/
    └── page.tsx              # Debug page for troubleshooting

components/admin/
└── financial-management.tsx  # Main financial management UI
```

### 3. API Endpoint

**Route**: `/api/financial-reports`

**Methods**:
- `POST`: Generate and download PDF reports
- `GET`: Get available report types

**Request Body**:
```typescript
{
  reportType: 'payment-report' | 'fee-structure-report' | 'outstanding-fees-report' | 'comprehensive-report',
  data: {
    payments?: Payment[],
    feeStructures?: FeeStructure[],
    assignments?: StudentFeeAssignment[]
  },
  options?: {
    format?: 'A4' | 'Letter',
    margin?: { top: string, right: string, bottom: string, left: string },
    header?: { title: string, subtitle?: string },
    footer?: { text: string, pageNumbers?: boolean }
  }
}
```

## Usage

### 1. In Financial Management

The PDF export functionality is integrated into the main Financial Management interface:

- **Main Header**: "Export All" button for comprehensive reports
- **Payments Tab**: "Export PDF" button for payment reports
- **Fee Structures Tab**: "Export PDF" button for fee structure reports
- **Student Fees Tab**: "Export PDF" button for outstanding fees reports

### 2. Test Pages

- **`/test-pdf-export`**: Test all PDF export functionality with detailed instructions and examples
- **`/test-pdf-debug`**: Debug page for troubleshooting PDF generation issues

### 3. Programmatic Usage

```typescript
import { usePDFExport } from '@/hooks/use-pdf-export'

function MyComponent() {
  const { 
    exportPaymentReport,
    exportFeeStructureReport,
    exportOutstandingFeesReport,
    exportComprehensiveReport,
    isGenerating 
  } = usePDFExport()

  const handleExport = async () => {
    await exportPaymentReport(payments)
  }

  return (
    <Button onClick={handleExport} disabled={isGenerating}>
      {isGenerating ? "Generating..." : "Export PDF"}
    </Button>
  )
}
```

## Troubleshooting

### 1. Common Problems

**PDF not generating**:
- Check Puppeteer installation
- Verify API endpoint is accessible
- Check browser console for errors
- Ensure sufficient server memory

**Poor PDF quality**:
- Adjust CSS for print media
- Optimize images and graphics
- Check font availability
- Test with different data sets

**Slow generation**:
- Implement pagination
- Optimize data queries
- Use background processing
- Cache frequently used reports

**Browser initialization errors**:
- Check server environment
- Verify Puppeteer dependencies
- Try the debug page at `/test-pdf-debug`
- Check server logs for detailed errors

### 2. Debug Mode

Enable debug logging for troubleshooting:

```typescript
// In pdf-generator.ts
const DEBUG = process.env.NODE_ENV === 'development'

if (DEBUG) {
  console.log('Generating PDF with data:', data)
}
```

### 3. Debug Page

Use the debug page at `/test-pdf-debug` to:
- Test API endpoint connectivity
- Verify data availability
- Check error messages

- View detailed logs

### 4. Error Recovery

The system includes automatic error recovery:
1. **Primary attempt**: Use Puppeteer for PDF generation
2. **Fallback attempt**: Use simple HTML generator
3. **Error reporting**: Provide detailed error messages
4. **User feedback**: Clear notifications about success/failure
