# Employee Management - Quick Start Guide

## Getting Started

This guide will help you quickly get started with the new Employee Management feature.

## Accessing Employee Management

1. Log in to your admin account
2. From the main dashboard, look for **"Manage Employees"** in the sidebar (shown with a briefcase icon 💼)
3. Click on **"Manage Employees"** to open the Employee Management dashboard

## Understanding the Dashboard

The Employee Management dashboard has 5 main tabs:

### 1. **Overview Tab** 
   - See employee statistics at a glance
   - View employment type distribution
   - Check employee status breakdown
   - Access quick actions

### 2. **Employees Tab**
   - View all employees in a table
   - Search and filter employees
   - Access individual employee details
   - Quick actions for each employee

### 3. **Leave Management Tab**
   - View leave requests (coming soon)

### 4. **Attendance Tab**
   - Record daily attendance (coming soon)

### 5. **Payroll Tab**
   - Process monthly payroll (coming soon)
   - View payroll history (coming soon)
   - Generate payslips (coming soon)

## Common Tasks

### Viewing All Employees

1. Go to the **Employees** tab
2. You'll see a table with all employees
3. Use the search bar to find specific employees
4. Use filters to narrow down results

### Viewing Employee Details

1. In the **Employees** tab, find the employee you want to view
2. Click the three-dot menu (⋮) in the Actions column
3. Select **"View Details"**
4. A dialog will open showing comprehensive employee information

### Searching for Employees

You can search by:
- Employee name (first or last)
- Email address
- Employee ID

Simply type in the search box and results will filter automatically.

### Filtering Employees

**By Employment Type:**
- Full-Time
- Part-Time
- Contract
- Temporary

**By Status:**
- Active
- Inactive
- Suspended
- Terminated
- Retired

Select your filters from the dropdown menus above the employee table.

### Basic Information:

### Employment Details:

### Emergency Contact:
- Contact name

## Reading the Dashboard Statistics

### Overview Statistics:

**Total Employees**: Count of all employees in the system

**Active Employees**: Currently employed and working

**Full-Time Staff**: Number of full-time employees

**Average Salary**: Average monthly salary across all employees

### Employment Type Distribution:
- Shows breakdown of employees by employment type
- Helps with workforce planning

### Employee Status Overview:
- Shows active, inactive, and suspended employees
- Helps identify staffing levels

## Tips and Best Practices

1. **Use Filters**: Don't scroll through all employees - use filters to find what you need quickly

2. **Regular Updates**: Keep employee information current for accurate reporting

3. **Export Data**: Use the export feature for backup or reporting purposes

4. **Check Statistics**: Review the overview tab regularly to monitor workforce metrics

5. **Employee Details**: Always verify employee details before making important decisions

## Troubleshooting

### Employee not appearing in list?
- Check your filters - make sure "All Status" and "All Types" are selected
- Clear the search box
- Refresh the page

### Can't see employee details?
- Make sure you have admin permissions
- Try refreshing the page
- Check your internet connection

### Statistics not updating?
- Refresh the page to reload data
- Check if new employees were added through the Teacher Management module

## Frequently Asked Questions

**Q: What's the difference between Teacher Management and Employee Management?**
A: Teacher Management focuses on academic aspects (subjects, classes, teaching). Employee Management focuses on HR aspects (employment, attendance, leave, payroll).

**Q: Do I need to add employees separately from teachers?**
A: No! Employee Management automatically uses data from the teachers table. All teachers are employees.

**Q: Can I edit employee information?**
A: Yes! Use the edit function in the employee details or table actions menu (coming soon).

**Q: How do I track attendance?**
A: Navigate to the Attendance tab and use the "Mark Attendance" feature (coming soon).

**Q: Can employees view their own information?**
A: This feature is planned for future updates - employee self-service portal.

**Q: How is salary information protected?**
A: Salary information is only visible to admin users. Additional permission controls are coming.

**Q: Can I export employee data?**
A: Yes! Use the "Export Data" button to download employee information in various formats.
